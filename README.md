# Шашки на Django

Онлайн-игра в русские шашки: регистрация и вход, база данных игроков и партий, игра с компьютером или с другим человеком, таблица лидеров.

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt

python manage.py makemigrations game   # создаёт таблицы для партий и ходов
python manage.py migrate               # создаёт базу db.sqlite3
python manage.py createsuperuser       # (необязательно) доступ к админке /admin/
python manage.py runserver
```

Откройте http://127.0.0.1:8000/ , зарегистрируйтесь и начните партию.

**Игра вдвоём:** второй игрок регистрируется (в другом браузере или в режиме инкогнито), вы создаёте партию с «другим игроком», а соперник нажимает «Играть» в списке открытых партий. Чтобы играть с другого устройства в одной сети, запустите `python manage.py runserver 0.0.0.0:8000` и откройте `http://<IP-вашего-компьютера>:8000/`.

## Что где лежит

| Файл | Назначение |
|---|---|
| `game/logic.py` | правила русских шашек (чистый Python, без Django) и простой ИИ |
| `game/models.py` | `Game` (партия, доска, чей ход, результат) и `Move` (история ходов) |
| `game/views.py` | регистрация, лобби, рейтинг, JSON-API партии (`state`, `move`, `resign`) |
| `game/forms.py` | форма регистрации (имя игрока, почта, пароль) |
| `game/templates/` | страницы сайта |
| `game/static/game/` | стили и `game.js` (доска, выбор хода, опрос сервера раз в 1,5 с) |
| `game/test_logic.py` | тесты правил: `python manage.py test` |

## База данных

Имена игроков хранятся в стандартной таблице пользователей Django (`auth_user`, пароли — в виде хэшей). Партии — в `game_game`, ходы — в `game_move`. Всё лежит в файле `db.sqlite3`; посмотреть и править данные можно в админке `/admin/`.

## Правила

- Играют на тёмных клетках; белые ходят первыми.
- Простая шашка ходит вперёд на одну клетку, бьёт вперёд и назад.
- Дамка ходит и бьёт по диагонали на любое расстояние.
- Бить обязательно, серию взятий нужно довести до конца (побитые шашки снимаются после хода, дважды через одну шашку прыгать нельзя).
- Шашка, дошедшая до последней линии, становится дамкой — даже если это произошло посреди взятия.
- Проигрывает тот, у кого не осталось шашек или ходов. Ничья — 15 ходов подряд только дамками без взятий. Можно сдаться.

Все ходы проверяются на сервере, поэтому подделать ход из браузера нельзя.

## Для публикации в интернете

Задайте переменные окружения `DJANGO_DEBUG=0`, `DJANGO_SECRET_KEY=<длинный секрет>` и `DJANGO_ALLOWED_HOSTS=ваш-домен.ru`, запускайте через gunicorn/uvicorn и выполните `python manage.py collectstatic` (потребуется добавить `STATIC_ROOT` в настройки и раздавать статику веб-сервером).
